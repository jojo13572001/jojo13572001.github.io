6. presion/recall, helpful to metric skewed class(rara condition like cancer) to avoid cheating on algorithm(keeping output a single value for all samples)

7. trade off between presion and recall(ex: only if h(theta) >= 0.7, y=1 so presion will be high, recall will be low; >= 0.3, y=1 presion will be low ,recall will be hight). It depends on goal.

8. Average = (presion+recall)/2 is not a good method to estimate algorithm quality; we usually use F1 score = 2*P*R/(P+R), if P or R equal zero, F1 equal zero

9. because we use F1 to descide the parameter threshold - h(theta) shoud >= threshold, so we shoud use validation set but not test set

## lecture 7
Logistric are very similar to SVM linear kernel which is convex optimization(can find global minization)

11. Features(10000) > sample size(10-1000), suitable to use SVM linear kernel or logistic regression. 

12. Feature small(1-1000), sample size(10-10000) is intermediate not very large, SVM gussian kernel(features == samples) is better. 

13. Feature small(1-1000), samples very large(500000+), SVM gussian will be very slow. It suggest that creating more features and use SVM linear instead.

14. Neural network may work well in the cases above with appropriate tuning but may slow more.
