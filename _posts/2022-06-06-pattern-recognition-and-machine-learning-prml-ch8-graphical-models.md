    8.4.4 The sum-product algorithm

Basic graphical models can use sum-product algorithm to calculate "joint distribution".
Basic graphical models can use max-sum algorithm to calculate "maximum posterior".
All the algorithms above are "exact" inference so are time consuming.
There is opposite method - approximate inference in chap 10 that is "not" exact inference but approximate inference.
