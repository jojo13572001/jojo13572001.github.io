# **Q-Learning (off-policy)**
Q Learning的思想完全根據 Q value iteration得到。明確一點說 Q value iteration每次都對 Q Table內所有的Q值更新一遍，也就是所有的狀態和動作。事實上在實際情况下我們無法遍歷所有狀態還有所有的動作，我们只能得到有限的樣本數，使用有限的樣本進行操作。Q Learning採用加權平均當前的Q value和新的Q Value來更新Q值。

# **Comparision**
當目前agent處於每個state時，有兩個主要工作，一個是*決定採取哪個action*，決定完成後同時也等於選擇了下一步State。接下來另一個目標就是*更新目前的Q(s,a)值*。

***Action值選擇：***
Q learning根據e-greedy策略，從已更新的Q(s,a)中選出action
Sarsa直接採用在上一個state時，根據e-greedy 選擇出來用來更新上一個Q值的action

***Action選擇完後，必須更新Q(s,a)：***
Q learning根據greedy策略，從下一步Q(s',a')中選出最大值來更新當前Q(s,a)
Sarsa根據e-greedy策略，從下一步Q(s',a')中選出最大值 or Random one來更新當前Q(s,a)
由上面劃底線可知，Q learning在更新當下Q(s,a時)會去使用下一個state最大的Q(s',a')，但是在來到下一個state時卻不一定會採用a'，而是採用e-greedy， 因此被稱為off policy；Sarsa由於採用e-greedy更新Q(s,a)，同時也一併採用當時計算出的a’為下一個state所一定用採用的action，因此被稱為on policy。
