## Associative Learing is a kind of unsupervised neural network design used for pattern recognition that has the following traning concept

1. Commonly Dog sees food  -> Salivate (unconditioned Stimulus)
2. Commonly Dog hears bell -> not Salivate
3. Training Dog sees food + hears bell at the same time
4. Make dog hear bell only -> it will Salivate (conditioning Stimulus)

## Competitive network is a extented unsupervised neural network used for pattern classifier. It's similar to Hamming network used for unsupervised learing pattern recognition.
