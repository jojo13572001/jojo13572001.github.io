1. Online learning setting algorithm uses continue stream(samples) to train your model, it's similar to stochastic gradient descnet. One of the advantage is the model will change as users's taste/trend change.

2. We can use logistic regression or neural network, ex: user input origin and destination(X1, X2) to ship their goods, we can give them adaptive price(X3) and retrieve final answer(Y) as one sample(X,Y). We can then try different X3 to apply to users.

3. Product Search (learning to search) Result is called predicted CTR(click through rate). We hope to create (X, Y) samples for online model learning - when we give user 10 search result link, the reason that user dicides to click or not(Y=0 or 1) depends on the result link's 
	3.1 phone features itself (fashion or not? Trend? Functionality?)
  3.2 how many words does query string match the phone name
  3.3 how many words does query string match the phone link's description

4. Map Reduce and Data Parallelism
	4.1 Once your algorithm (batch gradient descent) use summation of data set, like computation of gradiet. You can divide summation into several machines and combine them in central machine.
  4.2 Use one CPU's multi-core for parallelism. If you use linear algebra library with parallelism, it will use multi-core automatically.
